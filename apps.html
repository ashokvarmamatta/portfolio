SP

SimplePlayer — P2P Streaming Engine

Experimental · tech demo

A BitTorrent stream-while-downloading engine: paste a magnet link and playback starts after a few seconds of prebuffering — no waiting for the full download.

  • libtorrent4j with sequential download + head/tail piece boosting
  • Local HTTP server streams byte ranges to ExoPlayer as pieces arrive
  • Piece-aware stream blocks precisely until data is written — seek supported
  • Foreground service keeps the download alive in background
Version: 0.10.0-debug Build: 2026-07-16 Size: ~77 MB Requires: Android 7.0+
Known issues — read before installing
  • Experimental: UI is minimal; this is an engine demo, not a polished player
  • Seeking far ahead can stall until the needed pieces download
  • Malformed / decorated magnet links may fail — paste the clean URI only
  • Battery + data heavy while a torrent is active; debug build
  • Legal: BitTorrent is a content-neutral protocol. Only stream or download content you have the rights to (e.g. public-domain media, Linux ISOs, openly licensed files).
Download APK (77 MB)
